# UI reboot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the loud green/navy zombie UI with a minimalist, compact, Google-Drive-style interface using the approved slate/indigo palette.

**Architecture:** One global stylesheet (`src/styles.css`) is rewritten around tokens (colour, type, density, radii) plus a shared "row" pattern, then each Angular template is adapted to that pattern. No routing, dependency or behaviour changes; the same screens and endpoints.

**Tech Stack:** Angular 22 standalone components, signal state, one global CSS file, Cloudflare Worker + R2 + D1.

**Spec:** `docs/superpowers/specs/2026-11-05-ui-reboot-design.md` (read it with this plan; the catalogue behind it is `docs/UI-REBOOT.md`).

## Global Constraints

- No new dependency; no test framework. Verification is `npm run typecheck`, `npm run build`, `npm run check:scripts`, and real-browser checks with named assertions (browser-use).
- Uploads stay browser → R2 presigned. Do not touch the upload endpoints.
- Do not touch the `ngx-extended-pdf-viewer` toolbar, Video.js player internals, the moving watermark, or the Google sign-in button.
- Palette (light / dark): page `#FAFAF7`/`#0B1120`; surface `#FFFFFF`/`#111827`; hover `#F1F5F9`/`#1E293B`; text `#0F172A`/`#F8FAFC`; muted `#475569`/`#94A3B8`; primary `#4338CA`/`#6366F1`; primary-hover `#3730A3`/`#4F46E5`; on-primary `#FFFFFF`; link/active `#4338CA`/`#A5B4FC`; amber `#FBBF24` with `#0F172A` on it; success `#15803D`/`#4ADE80`; border `#E2E8F0`/`#334155`; danger `#DC2626`/`#F87171`.
- Type: Inter only, base 14 px / 1.45; wordmark 15/600; page title 20/600; section 15/600; row name 14/400–500; control 14/500; meta 12.5/400.
- Density: desktop row 40 px, phone row 44 px; controls 28 px (32 px primary in a bar); radii 6 control / 8 menu-input / 10 dialog.
- No gradients, no shadows except one soft shadow on dialogs and the search dropdown; borders do the separating.
- Indigo is the only interactive colour; amber only badges; green only done/saved; red only destructive.
- Theme: two-way Light ⇄ Dark toggle in the header menu, `data-theme` on `<html>`, remembered in `localStorage('theme')`, first paint follows `prefers-color-scheme` when unset.
- Direct commits and pushes to `main` are authorised.
- Never sign out the real admin browser session (`mbthunter007@gmail.com`).

## Review Focus

Inputs/conditions the spec implies but no task's tests can cover by themselves; check each during its task's browser step:

- **PDF full-window mode** after the notes bar merges into the lesson bar — the expanded overlay must still cover the viewport and the merged controls must still be reachable.
- **Long and non-Latin names** (emoji + Bengali section names, very long lesson titles) in rows, the lesson bar and the `⋯` menu — must truncate, not overflow or break the layout.
- **Theme first paint and persistence** — no flash of the wrong theme on reload, and the PDF viewer + video player follow the chosen theme.
- **Touch targets** — every phone row ≥ 44 px and every row action reachable, with `⋯` always visible when hover is unavailable.
- **Keyboard** — Escape closes the header menu, the `⋯` menu and dialogs; focus returns to the control that opened them.
